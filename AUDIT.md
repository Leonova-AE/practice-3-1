# Аудит неиспользуемых функций

Я искала экспортируемые функции в `src/`, которые не вызываются в `main.ts` (после перехода на класс `BookCatalog`).

| Название функции | Где находится | Полезная ли она? (Да/Нет) | Как её можно использовать в будущем? (Идея для фичи) |
| :--- | :--- | :--- | :--- |
| calculateAverageYear | task1-types.ts | Да | Показать в шапке сайта: «Средний год книг в коллекции: 2021» |
| formatBook | task1-types.ts | Да | Кнопка «Скопировать список»: выгрузить каталог текстом «Title (Year) — Authors». Сейчас её использует только `BookClass.format()` |
| filterByMinRating | task3-filters.ts | Да | Поле «Минимальный рейтинг» рядом с фильтром по году |
| addBook | task2-functions.ts | Нет | Дублирует метод `BookCatalog.addBook`. Удалена вместе с тестами |
| removeBook | task2-functions.ts | Нет | Дублирует метод `BookCatalog.removeBook`. Удалена вместе с тестами |
| getBook | task2-functions.ts | Нет | Работала только со старым словарём `Catalog`, а он после перехода на класс не нужен. Удалена вместе с тестами |
| filterAndSortBooks | task5-utils.ts | Нет | Просто склеивает `filterByTitle` и `sortBooks`, а в `main.ts` (`refreshList`) это уже делается. Удалена вместе с тестами |

## Что сделала

- Полезные функции оставила и добавила им JSDoc `@deprecated` (пока не используются, задел на будущую фичу).
- Бесполезные удалила вместе с тестами (`tests/task2.test.ts`, `tests/task5.test.ts`). Файл `task2-functions.ts` после этого стал пустым, поэтому удалён целиком. Тип `Catalog` нужен был только ему, его тоже удалила.
- `filterByTitle` и `sortBooks` в таблицу не попали: они вызываются в `main.ts` и внутри класса `BookCatalog`.
